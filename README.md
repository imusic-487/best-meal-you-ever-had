Entry for the [make.fun](https://make.fun) bounty **The Best Meal You Ever Had**
(`u-pangg7-the-best-meal-you-ever-had-a3ac0f85`).

`main.py` (Python 3.13, standard library only) writes one sentence —
at most 200 characters — about the best meal ever had to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), after
checking it against the competition gate: UTF-8 text, 1–200 characters,
not only whitespace, exactly one sentence.

Run it:

```sh
python3 main.py
```

## The entry

> At Da Michele in Naples I had the best meal of my life: a margherita
> blistered from the oven, basil torn over the top, eaten standing
> because sitting down would have wasted a second of it.

188 characters, one sentence.
